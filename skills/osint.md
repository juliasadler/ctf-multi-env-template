# OSINT · 公开情报收集

> 适用题型：只给一个人名/网名/邮箱/手机号/一张照片/一个域名，让你找出关联信息（"这个人的生日""这张照片在哪拍的"）。
> 前置：会用搜索引擎高级语法（`site:`/`filetype:`），知道 EXIF 是什么。

## 前置工具（Prerequisites）

- exiftool：照片元数据（`apt install libimage-exiftool-perl`）。
- 搜索引擎高级语法（`site:` / `filetype:` / 引号精确搜）：无安装成本，先会用。
- 反向图片搜索：网页版即可。

## 触发词

- 人名/网名/邮箱/手机号（身份标识，不是技术附件）
- 照片问地点/时间、域名/公司名问关联资产

## 能力边界

- 只查**公开**信息。社工库/撞库/钓鱼等非法手段是红线，绝不碰。
- 技术漏洞利用 → 去对应题型 skill；本 skill 只做情报收集。

## 识别特征

- 题目给的是身份标识（网名/邮箱/手机号），而不是技术附件 → OSINT。
- 给了一张照片问地点/时间 → 地理定位。
- 给了域名/公司名问关联资产 → 资产收集。

## 解题检查清单（按顺序走）

1. **先列已知标识**：把题目给的所有标识写下来（网名、邮箱、域名、照片），一个一个查，别混在一起。
2. **用户名/邮箱**：搜索引擎直接搜（加引号精确搜）；查该用户名在各平台是否注册（namechk 类思路，手工搜几个大平台）。
3. **照片**：先看 EXIF（`exiftool`，经纬度/拍摄时间）；再反向图片搜索；再看图里文字、招牌、建筑风格定城市。
4. **域名/资产**：`whois` 看注册信息；DNS 记录（A/MX/TXT）看关联；证书透明度（crt.sh 思路）找子域名。
5. **社媒交叉**：同一网名在不同平台的内容拼起来（生日、学校、城市），注意时间线一致性。
6. **收敛**：每条结论记来源 URL，答案要能"指着来源说出来"，不能靠猜。
> **防幻觉铁律**：数字、偏移、密钥、地址、flag 只写工具输出或文件里实际出现的值。

## 常用工具

| 工具 | 用来干什么 | 一句话用法 |
| --- | --- | --- |
| exiftool | 照片元数据 | `exiftool 照片.jpg \| grep -i -E "gps|create"` |
| 搜索引擎 | 人肉起点 | `"网名"` 加引号，`site:` 限定平台 |
| whois / dig | 域名情报 | 注册人、DNS 记录、MX |
| 反向图片搜索 | 以图搜图 | 找原图出处和拍摄地线索 |

## 常见坑

- 坑 1：用非法手段（社工库/撞库/钓鱼）→ 红线。OSINT 只查**公开**信息，凡是需要"黑进去"看的都不碰。
- 坑 2：同名同姓搞混 → 交叉验证（头像/时间线/关联人对上两个以上才算同一人）。
- 坑 3：EXIF 被清掉就放弃 → 反向搜图 + 图中文字/建筑，一样能定位。
- 坑 4：结论不记来源 → 写 Writeup 时说不清依据，裁判不认。
