# Patterns · 跨题型模式速查与绕过策略

> 适用题型：解题中途用。看到某个特征，来这里查"这个特征对应什么已知模式、去哪个 skill 深挖"。
> 前置：先读过 `triage.md`，知道自己在解哪类题。

## 前置工具（Prerequisites）

- 无重型工具。会看表就行；建议先读过 `triage.md`（知道自己在解哪类题）。
- 搜索引擎（找同类题解用），浏览器即可。

## 触发词

- "这个特征像什么""特征对不上清单"、解题中途想查"已知模式"
- "WAF 拦了""关键字被过滤"、想换思路不换 payload

## 能力边界

- 不讲具体题型的完整流程 → 模式命中后，去对应题型 skill 按清单验证。
- 不提供 payload 全文 → 只给绕过"原则"，细节去 `/secknowledge` 或对应 skill。

## 识别特征（特征 → 模式 → 动作，即 Observer 漂移检测 / 模式自动注入）

| 看到什么特征 | 可能的模式 | 动作 |
| --- | --- | --- |
| `checksec` 显示 NX 没开 | ret2shellcode | 去 `pwn.md` 第 3 步 |
| 输入直接进 `printf` | 格式化字符串 | 去 `pwn.md` 第 4 步 |
| 菜单题（增删改查堆块） | 堆利用（UAF/tcache） | 去 `pwn.md` 第 5 步 |
| JWT 三段式，`alg` 可改 | 算法混淆（none/弱密钥） | 去 `web.md`，查 jwt_tool |
| URL 参数有 `?url=` / `?callback=` | SSRF | 去 `web.md` 第 4 步 |
| 返回数据里有 `userId` / `orderId` | IDOR（越权） | 改 ID 重放，看回显 |
| `{{7*7}}` 回显 49 | SSTI（模板注入） | 测模板引擎类型再找 payload |
| `srand(time(0))` / `rand()` | 可预测随机数（LCG） | 爆破种子或反推序列 |
| `.wasm` 附件 | WASM 逆向 | `wasm-objdump` 看导出函数 |
| PNG 附件 | LSB/隐写 | 去 `misc.md` 第 2 步 |
| `n e c` 三个大数 | RSA | 去 `crypto.md` 第 3 步 |
| 相同明文块密文块相同 | AES-ECB | 去 `crypto.md` 第 4 步 |
| WAF 拦关键字 | 大小写/双写/注释符/编码绕过 | 见下方"绕过策略" |
| 同一 payload 试 3 次都没反应 | 换方向，不是换 payload | 回 `triage.md` 第 5 步 |

## 解题检查清单（按顺序走）

1. **特征匹配**：把当前看到的现象在上表里找，命中 → 按"动作"列走。
2. **没命中**：描述特征（3 个关键词）去搜同类题解，搜到的方法先在本地验证再用。
3. **命中但走不通**：看是不是被拦（WAF/过滤）→ 走"绕过策略"。
4. **记录**：新发现的"特征→解法"对子，回填到本表（见《使用与协同评估.md》新增流程）。

## 绕过策略（通用原则，不写具体题 payload）

- **关键字过滤**：大小写混写、双写（`selselectect`）、注释符/换行替换空格、URL 编码一次/两次。
- **长度/次数限制**：分段写入、短 payload 先探路。
- **算法混淆点**：凡是"客户端可选算法/模式"的地方（JWT alg、加密模式参数），都试试改成最弱的那档。
- **3 次原则**：同一思路 3 次无新 Fact → 停，换模式，不换 payload 变体。

## 常见坑

- 坑 1：把本表当"标准答案"背 → 它是"线索索引"，命中后还是要去对应 skill 按清单验证。
- 坑 2：绕过策略试了一箩筐，方向错了 → 先确认漏洞点真实存在（回显/报错/时间差），再谈绕过。
- 坑 3：新模式不回填 → 下次还得重新发现。好用的"特征→解法"记下来。
