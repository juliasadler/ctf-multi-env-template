# 题目目录说明

## 分类

`web`、`pwn`、`crypto`、`reverse`、`forensics`、`misc`、`osint`、`ai-ml`、`malware`。
分类名由脚本校验，不够再加，不改已有分类名。

## 新增题目流程

跑脚本，不要手工加行：

```bash
./scripts/add-challenge.sh <题名> <分类> <分值> [难度] [简称]
```

例如：`./scripts/add-challenge.sh "简单的登录" web 100 易 login`

脚本在锁内自动完成：取最大号 + 1（格式 `CTF-001`，`CTF-000` 示例不计入最大号）→ 建目录 `challenges/<分类>/CTF-xxx-<简称>/`（简称只用小写字母、数字、连字符）→ 按 `templates/题目说明模板.md` 生成题目说明 → 在 `../解题清单.md` 插行（状态 `未开始`）。
附件放题目目录下的 `files/` 里（不要放 flag 答案）。
登记后立即复查清单，重号时后登记方让位。
新增后在 `../更新日志.md` 记一笔（涉及共享清单行数变化，属共享结构改动；按《协议与约束.md》第 9 条写日期、改了什么、谁改的）。

## 规则

- `challenges/` 是正本，只读心态。解题时把附件复制到自己的工作目录再动。
- 不要在题目说明里写 flag、解法、完整 payload，只写题目本身给的信息。
- 题目删了也不回收编号，清单里把状态改成备注说明即可。
