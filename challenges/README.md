# 题目目录说明

## 分类

`web`、`pwn`、`crypto`、`reverse`、`forensics`、`misc`，不够再加，不改已有分类名。

## 新增题目流程

1. 先读 `../解题清单.md`，取最大号 + 1，格式 `CTF-001`。
2. 建目录：`challenges/<分类>/CTF-xxx-<简称>/`，简称只用小写字母、数字、连字符。
3. 按 `../templates/题目说明模板.md` 写 `题目说明.md`，附件放同目录的 `files/` 里（不要放 flag 答案）。
4. 在 `../解题清单.md` 加一行：编号、题目、分类、难度、题目路径、状态 `未开始`，其余先写 `-`。
5. 登记后立即复查清单，重号时后登记方让位。
6. 在 `../更新日志.md` 记一笔新增题目。

## 规则

- `challenges/` 是正本，只读心态。解题时把附件复制到自己的工作目录再动。
- 不要在题目说明里写 flag、解法、完整 payload，只写题目本身给的信息。
- 题目删了也不回收编号，清单里把状态改成备注说明即可。
